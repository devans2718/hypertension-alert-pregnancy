# Open Benchmark Dataset

This directory contains open, de-identified benchmark data used to ground patient vital sign distributions.

## Dataset: Maternal Health Risk Data Set
- **Source**: UCI Machine Learning Repository (DOI: 10.24432/C5DP5D)
- **Dataset URL**: https://archive.ics.uci.edu/dataset/863/maternal+health+risk
- **Upstream Archive**: https://archive.ics.uci.edu/static/public/863/maternal+health+risk.zip
- **Reference**: Ahmed, M., Kashem, M.A., Rahman, M., & Khatun, S. (2020). Review and Analysis of Risk Factor of Maternal Health in Remote Area Using the Internet of Things (IoT). *In Proceedings of the International Conference on Computing Advancements (ICCA 2020)*.
- **License / Terms**: CC BY 4.0 (open access, redistributable with attribution).
- **Content**: De-identified vital signs and metabolic markers (`Age`, `SystolicBP`, `DiastolicBP`, `BS`, `BodyTemp`, `HeartRate`, `RiskLevel`), exactly matching the 1,014 records in the upstream UCI release.
- **Usage**: Used as an open-data baseline for blood pressure ranges and patient risk categories in the demo application. Contains no Protected Health Information (PHI) or personal identifiers.
